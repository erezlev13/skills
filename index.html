Install the complete plugin

  1. Download the plugin ZIP above.
  2. If your ChatGPT Work interface offers Plugins → Add → Upload plugin archive, select the ZIP and review it.
  3. Finish installation, then open a new conversation if the skills have not appeared.

Updating? Use the update or replacement flow available in your interface and verify version 1.0.3. Changes to this repository do not automatically update an installed upload. This ZIP includes both skills and their supporting resources.

For Codex, copy a complete skill folder from providers/codex/ into ~/.codex/skills/. Full instructions ↗

Interactive output depends on the host's renderer. Chat questions use its supported conversation bridge; otherwise the guide offers a message to copy into chat. A skill cannot unlock unavailable host features.
