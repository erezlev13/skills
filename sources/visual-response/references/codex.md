# Codex capability adapter

Distinguish a terminal session from a desktop host with an explicitly exposed rendering contract.

- Terminal-only CLI: default to Markdown, tables, and code references. Do not generate HTML merely because an answer crosses a count threshold. For an explicit interactive request, disclose the inline limitation; provide a standalone browser-openable artifact only when requested or accepted. Do not invent a chat bridge or rendering token.
- Desktop/Work with a documented visual capability: read that capability's current instructions and applicable component guides. Follow its output paths, theme tokens, content restrictions, and delivery reference. A desktop label alone is insufficient.
- Requested standalone deliverable: use normal project/artifact workflows and a verified file link. The fragment validator does not validate full HTML documents.

Keep routine coding changes and status updates in text. A decision comparison or mechanism explanation can justify a visual if interaction materially helps. Cite verified file:line references or qualified symbols for code evidence. Do not claim browser behavior was tested when only source inspection was possible.
